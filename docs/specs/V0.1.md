# V0.1 — контракты маршрутизации и CLI

Статус: спецификация первого запускаемого инкремента. Python 3.11+.
Без runtime-зависимостей, сетевых вызовов и исполнения пользовательских действий.

## Вход Task (schema_version = "0.1")

JSON-объект с ровно следующими обязательными полями:

- schema_version: строка "0.1";
- task_id: непустая строка до 128 символов;
- goal: непустая строка до 10000 символов;
- capabilities: массив уникальных значений CUA, LLM, PERCEPTION (может быть пуст);
- allowed_routes: такой же массив, явно заданный вызывающим клиентом.

Неизвестные поля, повторённые JSON-ключи, невалидный UTF-8, NaN/Infinity,
неправильные типы и неизвестные enum отклоняются. Строки сохраняются без
молчаливого преобразования. Размер входа ограничен 64 KiB.
capabilities — объявление для синтетического routing-only прогона, не доказательство
подключения исполнителей. allowed_routes — фильтр клиента, не полноценная
система авторизации. Цель не исполняется и не анализируется заглушкой.

## RoutingDecision

schema_version, task_id, status (selected/abstained), route (enum/null),
eligible_routes, reason_code, provider="stub", is_stub=true, execution_performed=false,
confidence=null. Успех маршрутизации не является completed исходной задачи.

Eligible routes — пересечение capabilities и allowed_routes в фиксированном
порядке CUA, LLM, PERCEPTION. Заглушка выбирает первый вариант:
reason_code=stub_fixed_order. Если пересечение пусто: abstained,
route=null, reason_code=no_eligible_route. Ни эвристик по goal, ни Jev в V0.1 нет.
Публичные конструкторы контрактов также проверяют согласованность данных.

## CLI

reflexmesh route --input FILE
reflexmesh route --input -

--input по умолчанию «-» (stdin). Те же команды доступны через
python -m reflexmesh. stdout: один JSON-объект результата, UTF-8.
Ошибка: stdout пуст, stderr содержит один JSON-объект error с code/message.
Коды выхода: 0 selected, 3 abstained, 2 ошибка ввода/аргументов/чтения.
--help и --version — обычный текст и код 0. Неожиданные внутренние ошибки
не маскируются под ошибки пользователя; их устойчивый протокол вне V0.1.

## Приёмка

- Установка пакета даёт рабочую команду reflexmesh.
- CLI читает файл и stdin; результат явно помечен заглушкой.
- Все подмножества capabilities/allowed_routes выбирают только допустимый маршрут.
- Пустое пересечение даёт отказ, не случайный fallback.
- Ошибки схемы/кодировки/размера имеют согласованные stderr и exit code.
- Контракты нельзя создать с неизвестным или запрещённым маршрутом.
- CLI не вызывает исполнителей, не требует Pi, ключей или сети.

Связь с инвариантами: INV-01, 03, 04 (только фильтрация объявленных маршрутов),
07, 13. Остальные требования применяются на последующих этапах.
V0.2 заменит заглушку реальным адаптером; результаты V0.1 не оценивают качество Jev.
