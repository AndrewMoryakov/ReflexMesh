## Suite `provider-error`: live-ошибка провайдера, pass

JevRouter запущен с **заведомо неверным** ключом OpenRouter (`/health` по-прежнему
`openrouter:~typesafe/jev-latest` — health не проверяет ключ).
Результат ReflexMesh: `status=failed`, `reason_code=provider_error`, `route=null`,
exit 5; receipt upstream `jev_auth_error`, `decision.selected` пуст. Выбора по
умолчанию или скрытого fallback нет, текст ошибки провайдера в вывод не попал.
