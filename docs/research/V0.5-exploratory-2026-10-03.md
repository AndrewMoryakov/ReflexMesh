# V0.5 — exploratory browser runs, 2026-10-03

**Not acceptance evidence.** These runs used the operator host while the acceptance machine (a-moryakov-nb) was unreachable. They exercise the [B manifest](../../experiments/v05/bj-manifest.json) and the real-browser adapter tests once, to find defects before the frozen B/J attempts. The V0.5 gate stays open until B (3 × each subcase) and J run on the acceptance machine.
