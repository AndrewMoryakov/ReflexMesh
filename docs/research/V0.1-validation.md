# Проверка V0.1

Дата: 2026-09-23. Среда: Linux, Python 3.12.14.
Проверено рабочее дерево, включённое в коммит с этим отчётом.

- `python -m unittest discover -s tests -v`: 10 тестов прошли.
  Внутри тестов: все 64 сочетания подмножеств routes, негативные схемы,
  прямое создание контрактов, stdin/file, отказ, ошибки аргументов,
  malformed/duplicate/non-finite JSON, UTF-8 и лимит размера.
- `python -m pip install --no-build-isolation --no-deps -e .`: успешно.
- Установленная команда `/root/.local/bin/reflexmesh route --input examples/route-task.json`:
  exit 0, CUA, provider=stub, is_stub=true, execution_performed=false.
- `python -m reflexmesh route --input examples/route-task.json`: тот же результат.
- `git diff --check`: успешно.

В этой среде пользовательский каталог исполняемых файлов не входит в PATH;
поэтому установленная команда проверялась по абсолютному пути. README
рекомендует запуск из виртуального окружения без зависимости от глобального PATH.

Ограничения: Windows и Python 3.11 отдельно не запускались. Jev, Cua, MCP,
Pi и качество интеллектуальной маршрутизации не проверялись и не реализованы.
Этот отчёт не подтверждает execution-инварианты будущих версий.
