Historical local-environment report. Its results and environment description are preserved below; the [2026-10-07 static addendum](#static-review-addendum-2026-10-07) incorporates later evidence without claiming new execution.

Status: **in progress; the V0.5 acceptance gate is open.** This report describes local commit `1887114` and the deterministic checks executed against it. It is not a browser or live-provider acceptance report.

## Implemented and checked

- Strict `execution-task/0.1` validation, explicit `reflexmesh run` CLI, result and trace artifacts, and distinct blocked, failed, incomplete, cancelled, and completed states.
- A worker process and parent supervisor with shared dispatch/cancellation gate, step and model-call counters, wall deadline starting before fixture admission and macro routing, bounded grace, process-group termination, and unknown-effect recording. Jev macro requests are charged before dispatch; opaque micro-provider retries are disabled.
- Optional integration with SystemOneHarness controller, a deterministic script provider, a fixture-specific Browser Use adapter with target identity checks, immutable TextSlot references, and permission checks.
- Isolated HTTP fixture with run ID and event sequence; read-only verifier for the five proposed postconditions.
- On Linux/Python 3.12.14: `PYTHONPATH=src:../.deps:../SystemOneHarness python -m unittest discover -s tests -q` passed **85/85** tests. They cover deterministic process races, input errors, pinned harness integration without a browser, fixture state, and simulated browser adapter checks. No real-browser subcase is counted in this total.
- The frozen [U manifest](../../experiments/v05/u-manifest.json) yielded **36 passed, 0 pending, 0 failed** on commit `1887114`. See the [acceptance note](V0.5-U-acceptance.md) and [machine-readable results](V0.5-U-results.json). The first exploratory run, before complete coverage, is preserved separately as [initial results](V0.5-U-initial-results.json).

The optional harness checkout was pinned at `ab8e8f08b4a6268c0633a474423d556599ee06a4`. Browser Use `0.13.10` was installed in a separate local dependency directory and imports successfully; Chromium was not available. The attempted Playwright Chromium download returned an unusable archive from its CDN. No browser action was run in this environment.

## Open acceptance work

All listed U subcases from the [V0.5 acceptance matrix](../specs/V0.5.md#9-fixed-acceptance-gate-r7) are represented in the frozen U manifest and passed once. **All B and J subcases are pending**, including three fresh-fixture repetitions per subcase. The U pass uses fakes and a local harness script; there is no Jev micro-provider or JevRouter macro live receipt in this implementation pass.

Known implementation gaps against the specification:

1. The real Browser Use selector-map and backend-node behavior has only simulated tests; page/frame identity, destination/form identity, and live policy-revocation checks still need browser evidence and, where necessary, implementation changes.
2. Action sequences, postcondition observation times, redacted evidence references, late effect reconciliation, and a budget constraint check are present. Other required runtime constraints and authoritative reconciliation of every unknown action are incomplete. Model cost remains unmeasured and explicitly null.
3. The gate has a bounded lock wait, but a worker crash while holding the lock and full process-tree cleanup timing have not been demonstrated with the required acceptance fixtures.
4. The U manifest records each deterministic subcase, but the B/J manifest expansion, real dependency versions, exact live commands, provider identities, and repeated results remain to be frozen and collected.

Next: close the remaining adapter and runtime-contract gaps, install a working Chromium binary, freeze B/J subcase commands, run B three times per variant, then J three times per variant with configured live providers. Update milestone status only after recording each planned attempt and its evidence.
